# Butter conceptual examples

Illustrative TypeScript for the vision in [`../ideas/butter-vision.md`](../ideas/butter-vision.md).

These files document the **intended DX**. They are not wired to a real `butter` implementation yet. Imports from `butter`, `butter/extensions`, and `butter/adapters` are aspirational.

Read them in order:

1. Builder setup
2. Rename models and methods
3. Override and augment
4. Extension contribution
5. Contract → client + RPC
6. Adapter boundary
