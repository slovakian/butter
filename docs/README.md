## Why Better Auth is referenced

Butter is an Effect-native authentication library positioned as a [Better Auth](https://github.com/better-auth/better-auth) alternative. Agents implementing Butter features often need to understand how Better Auth solves the same problems — session handling, plugins, adapters, OAuth flows, and so on — before translating those patterns to Effect.

Use the [Better Auth reference guide](./better-auth-reference.md) for the recommended ways to fetch that upstream context.
